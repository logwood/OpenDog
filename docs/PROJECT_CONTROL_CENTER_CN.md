## 接管规则

1. 新会话开始时先读取本文件、`SESSION_STATE_CN.md` 和 `models/registry.json`。
2. 一个会话只承担一个有明确产物的 bounded task；完成后把 commit、输入哈希、命令、指标、结论和未完成事项回传中控。
3. 远端训练必须使用新实验目录；启动前检查 commit、manifest、checkpoint、GPU 和已有目录，禁止覆盖或重复启动。
4. 研究结果必须同时报告 baseline、候选、paired-error、MRR/AUC、开放集指标和资源开销；只有“净收益稳定且无害”才允许晋级。
5. `notLoaded`/`idle` 会话只读取一次最近结论即可；不要反复发送“继续”制造重复工作。
6. blind split 一旦消费，禁止用其结果调参；未知标签的 Phase B 只做预测和定性检查，不声称官方 AUC。
7. 任何新结论若不写回本文件或专项实验记录，就视为未纳入项目状态。
